# مراجعتي

أداة شخصية لمراجعة حفظ القرآن الكريم (مصحف المدينة، رواية حفص عن عاصم).

## المصادر
- نص المصحف: مجمع الملك فهد لطباعة المصحف الشريف، نسخة 18 (Unicode).
- تخطيط الصفحات وخطوط الصفحات: مصحف المدينة 1441 هـ، حزمة `quran-qcf4` (تُحمَّل من jsDelivr ولا تُنسخ هنا).
- التفاسير (الميسر، السعدي، ابن كثير): نصوص من quran.com دون تعديل.
- التلاوة: تُبَثّ من everyayah.com و mp3quran.net ولا تُخزَّن هنا.

الاستخدام شخصي. حقوق النصوص والخطوط والتسجيلات لأصحابها.
